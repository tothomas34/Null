2. Théorie — la fiche courte

2.1 Positions et vecteurs

Une position est un point dans le monde. Pour aller du garde G à la cible P :

toTarget = P - G

Le signe et l’ordre comptent : G - P pointe dans la direction inverse. Une direction unitaire a une longueur de 1 ; elle conserve l’orientation, pas la distance.

2.2 Contrat top-down XZ

Dans ce jeu, Y est la verticale. On raisonne sur le sol :

flatToTarget = new Vector3(delta.x, 0f, delta.z)
flatForward  = new Vector3(forward.x, 0f, forward.z)

La projection est faite avant le test de distance et avant la normalisation. Si le vecteur horizontal est quasi nul, la direction n’est pas définie : le Floor retourne false.

2.3 Dot product

a · b = ax*bx + ay*by + az*bz
a · b = |a| * |b| * cos(θ)

Si a et b sont unitaires, a · b = cos(θ). Sur [0°,180°] : plus le dot est grand, plus l’angle est petit.

Angle Cosinus Lecture
0° 1.000 parfaitement en face
30° 0.866 proche de l’axe
45° 0.707 bord d’un FOV total de 90°
90° 0.000 sur le côté
180° -1.000 derrière

2.4 Test de cône et portée

Pour un FOV total de 90°, le demi-FOV vaut 45°. Le seuil est :

cosHalfFov = cos(fieldOfViewDegrees * 0.5 * Deg2Rad)
insideAngle = dot(unitHeading, unitToTarget) >= cosHalfFov

La frontière est incluse (>=). Pour la portée :

withinRange = flatToTarget.sqrMagnitude <= maxDistance * maxDistance

On ne calcule pas une racine carrée quand on ne cherche qu’une comparaison.
